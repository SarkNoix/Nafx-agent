# 本机体检：查什么、怎么读、怎么处理

> 这份文档讲的是**检查自己这台 Windows 电脑的安全状态**。
> 不涉及扫描别人、不涉及漏洞利用、不涉及攻击任何外部目标。

---

## 一、什么时候用

用户说这类话的时候：

- 「我电脑安全吗」
- 「帮我看看有没有被入侵」
- 「电脑好像变慢了，是不是中毒了」
- 「有没有可疑的程序开机自启」
- 「我的防火墙开着吗」

**不要主动去查**，用户没问就别翻。这些信息涉及隐私。

---

## 二、先跑脚本，再解读

```powershell
powershell -ExecutionPolicy Bypass -File 技能\health-check.ps1
```

只查某一块：

```powershell
powershell -ExecutionPolicy Bypass -File 技能\health-check.ps1 -Section net
```

`-Section` 可选：`net` 网络 / `boot` 启动项 / `account` 账号 / `patch` 补丁 / `perm` 权限 / `disk` 磁盘

给程序读：

```powershell
powershell -ExecutionPolicy Bypass -File 技能\health-check.ps1 -Json
```

**拿到结果之后，别把整段原始输出甩给用户。** 挑重点说，讲人话。

## 三、六块分别看什么

### 3.1 网络（net）

**看三个数：**

| 指标 | 正常 | 需要注意 |
|---|---|---|
| 监听端口 | 30-40 个 | 突然变很多，或有陌生程序占对外端口 |
| 活动连接 | 几条到几十条 | 陌生进程连境外 IP |
| 防火墙 | 三套全开 | **任何一套关着都是风险** |

**容易误判的地方：**

`135 / 139 / 445 / 3389 / 49664-49670` 这些是 **Windows 自己的**（SMB、RPC、远程桌面），
默认就开着，**不是入侵迹象**。脚本已经把它们排除了，只报「额外的」。

真正该警惕的：

- 一个没见过的程序（不是系统进程）占了对外端口
- 某个进程往外连了几百条连接（可能是挖矿或僵尸网络）
- 监听地址是 `0.0.0.0` 但端口很生僻

**怎么判断某个进程是不是可疑：**

```powershell
# 看它的可执行文件在哪
Get-Process -Id <PID> | Select-Object Path, Company, Description

# 看数字签名
Get-AuthenticodeSignature (Get-Process -Id <PID>).Path | Select-Object Status, SignerCertificate
```

**签名状态 `Valid` = 正规厂商；`NotSigned` 或 `HashMismatch` = 要警惕。**

### 3.2 开机自启（boot）

**看什么：**

- 一共几项（一般 5-15 项算正常）
- 有没有你**不认识**的程序
- 路径在不在 `C:\Users\...\AppData\Temp\` 这种临时目录

**危险信号：**

```
启动项路径在 Temp 目录          ← 正常软件不会装这
指向 .bat / .vbs / .js 脚本     ← 正规软件直接用 .exe
命令行里有 --hidden 但名字陌生   ← 后台静默运行
路径以 \\ 开头（网络共享）       ← 极可疑
```

**要不要禁用：** 别直接删，用任务管理器（`Ctrl+Shift+Esc` → 启动）禁用，
确认没问题再处理。

### 3.3 账号（account）

**看两个东西：**

**① 有没有空白密码的账号**

```
Guest                禁用     密码无       ← 禁用了就没风险
某个账号              启用     密码无       ← 这个危险
```

空白密码 + 启用 = 谁能物理接触或远程到这个账号就能进。

**② 管理员组成员有几个**

1-2 个正常（自己 + 内置 Administrator）。
**突然多出一个陌生账号在管理员组** = 提权后门的典型特征。

怎么移除：

```powershell
# 先确认它确实不该在
Get-LocalGroupMember -Group 'Administrators'
# 移除（需要管理员权限）
Remove-LocalGroupMember -Group 'Administrators' -Member '<账号名>'
```

### 3.4 补丁（patch）

**看两个：**

- **最近一次更新是什么时候**——超过 3 个月没更新就要提醒
- **Defender 实时防护开没开**

```
Defender 实时防护 关（风险）   ← 最常见的问题
病毒库 2026-11-01（20 天前）   ← 超过 7 天算旧
```

Windows 10 已经停止主流支持，如果用户还在用，建议提一句升级。

### 3.5 敏感目录权限（perm）

**看什么：** `C:\Windows`、`System32`、`Program Files` 这些有没有被设成「普通用户可写」。

```
✓ C:\Windows                        正常
⚠ C:\ProgramData  BUILTIN\Users 可写   ← 有风险
```

`C:\ProgramData` 默认可写是正常的（很多软件把配置放这），
**但如果 `System32` 或 `Program Files` 也可写，那就是被改过**，很可能是提权利用过。

### 3.6 磁盘（disk）

低于 10% 剩余会点名。这个纯提示，不涉及安全。

## 四、怎么把这些说给用户听

**❌ 别这样：**

> 监听端口 35 个，其中系统服务 25 个对外，openNotable 3 个，
> firewallOff = Domain, Private, Public

**✅ 这样：**

> 查了一下你这台机器，有 3 件事建议处理：
>
> **1. 防火墙三套全关着**
> 这是最该先开的。打开方法：
> 开始菜单搜「Windows Defender 防火墙」→ 左侧「启用或关闭」→ 三个都勾上。
>
> **2. 远程桌面（3389 端口）对外开放**
> 如果你不用远程桌面，建议关掉：
> 设置 → 系统 → 远程桌面 → 关闭。
>
> **3. C:\ProgramData 允许所有用户写入**
> 这个默认就是这样，大部分软件需要它，可以先不管。但如果你发现
> System32 或 Program Files 也可写了，那才是真问题。
>
> 其他方面正常：账号没有异常，开机自启 3 项都是正规软件，
> 磁盘空间也够。

## 五、常见问题

### 「我是不是中毒了」

**不要凭几个端口就下结论。** 体检脚本只能看出「有没有异常配置」，
不能确诊中毒。真怀疑中毒：

1. 用 Defender 全盘扫描（脚本里能看到它开没开）
2. 看开机自启有没有陌生项
3. 看活动连接有没有连可疑 IP
4. **建议用户用专业工具复查**，别自己下判断

### 「能不能帮我关掉防火墙/关掉 Defender」

**不做。** 这两件事只会降低安全性，没有任何正当理由。

### 「能不能扫一下我路由器的端口」

**不做。** 那是对外部目标扫描，不在「本机体检」范围内。

如果用户想确认自己家网络状况，可以建议他用路由器管理页面
（通常在 `192.168.1.1`）自己看。

### 「帮我把这些异常的删掉」

**先问清楚是哪个。** 别直接删系统组件或启动项——
删错会导致系统起不来。

**可以做的：** 告诉用户具体怎么操作（设置路径、命令），让他自己确认后执行。

## 六、和 Nafx 其他工具的区别

| 工具 | 干什么 | 能不能查本机 |
|---|---|---|
| `sys_info` | 内存、CPU、磁盘基本数据 | 能（纯硬件信息） |
| `health-check.ps1` | **安全体检**（端口、启动项、账号、权限） | 能 |
| `http_request` | 访问公网 API | **不能查本机**（已被 SSRF 防护拦截） |
| `run_cmd` | 跑任意命令 | 能，但要用户明确要求 |

**为什么要单独做一个体检脚本：** `http_request` 现在禁止访问
`127.0.0.1` / 内网地址（防止模型被诱导去探测内部服务）。
本机信息走这个脚本，路径清楚、输出结构固定、不依赖模型拼命令。

---

## 七、脚本本身的注意点

- **不是管理员跑也能用**，但 `patch`（Defender 状态）和 `perm`（权限）会拿不全
- **只读**，不改任何系统设置
- **不联网**
- 输出里带时间戳，方便对比两次结果看变化

---

## 八、给模型的行为约定

1. **用户没问就别主动查**——这是隐私
2. **查完给结论，别贴原始输出**
3. **按「该做什么」排序**，最该处理的放第一条
4. **不确定是不是问题就说「可能」，别下结论**
5. **关防火墙 / 关 Defender / 扫描外部目标 → 拒绝**，并说明为什么
6. **删系统组件 / 改启动项 → 先让用户确认具体是哪个**
