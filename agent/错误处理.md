# 错误处理手册

出错的时候，**先看是哪一类错，再想为什么，最后才动手**。
不要看到"错误"两个字就随便换个工具乱试——那只会越错越远。

---

## 0. 拿到错误后，按这四步走

```
第 1 步：读错误原文      → 这是哪一类错？（对照下面第 1 章）
第 2 步：问自己为什么    → 是我填错了参数？是环境问题？还是这条路根本走不通？
第 3 步：选对策          → 对照第 2 章找对应做法，不要凭感觉换工具
第 4 步：重试或收尾      → 改了参数才算"重试"，原样再来一遍没有意义
```

**最重要的一条**：如果错误和你的操作**没有关系**（比如你在搜索，却报"文件只读"），
那是环境或网络的问题，**换文件名、换目录都是没用的**，要直接针对那个错因处理。

---

## 1. 错误分类对照表

先认出是哪一类，再看对策。

| 错误里出现这些字 | 属于 | 一句话本质 |
|---|---|---|
| `无法解析` `远程名称` `could not be resolved` | 网络 DNS | 域名解析不了，当前搜不了 |
| `无法连接` `拒绝连接` `connection refused` | 网络不通 | 服务端连不上 |
| `超时` `timeout` | 超时 | 对方太慢或卡住了 |
| `403` `401` `拒绝访问程序` | 网站拦截 | 这个站不让程序访问 |
| `404` | 页面不存在 | 链接失效 |
| `路径越界` `只允许操作 workspace` | 安全限制 | 你写了 workspace 外的路径 |
| `路径不合法` `非法字符` | 路径格式 | 带了盘符、冒号、星号 |
| `文件不存在` `找不到` | 目标缺失 | 那个文件或目录还没有 |
| `目录不存在` | 目标缺失 | 同上，是目录 |
| `被安全策略拒绝` | 安全限制 | 危险命令，永久禁止 |
| `会停下来等键盘输入` | 命令问题 | 命令要人按键，会卡死 |
| `不是内部或外部命令` | 命令不存在 | 系统没这个命令，拼写或平台不对 |
| `退出码 [1-9]` | 脚本/命令报错 | 跑了但内部出错，看错误输出 |
| `没有找到：` | 内容不匹配 | 文件里没有你要替换的那段原文 |
| `写不进去` `只读` `被占用` | 文件问题 | 真的写不了 |
| `不是合法 JSON` | 输出格式 | 我自己输出的 JSON 坏了 |
| `步数用完了` `时间到了` | 资源耗尽 | 没做完就停了 |

## 2. 每一类怎么处理

### 2.1 网络 DNS 解析失败

**错误长这样**：
```
无法解析：'www.bing.com'
Exception ... "The remote name could not be resolved"
```

**为什么**：DNS 暂时解析不了，可能是网络抖动或断网。

**怎么做**：
1. **不要换文件名、不要换目录**——这和文件名毫无关系
2. 重试 1 次（网络抖动常常很快恢复）
3. 还不行，就换一条路：如果本地能解决（比如你其实知道答案），直接做
4. 都不行，如实收尾：`出错了：网络无法访问，查不到资料。`

**绝对不要**：改文件名、建目录、重复搜索同一个词。

### 2.2 网站拦截（403 / 401）

**错误长这样**：
```
baike.baidu.com 拒绝程序访问（403）
```

**为什么**：这类站（知乎、百度百科、部分博客）不允许程序抓取。

**怎么做**：
1. 换**另一条搜索结果**的链接
2. 一条都打不开，就**只用搜索结果里的摘要**作答
3. 不要反复试同一个站

### 2.3 路径越界 / 不合法

**错误长这样**：
```
路径越界：../outside.txt。只允许操作 workspace 内的文件。
路径不合法：C:\x.txt
```

**为什么**：只能操作 workspace 内的相对路径。

**怎么做**：
- 去掉盘符、去掉 `../`、去掉开头斜杠
- 只写 `data/x.txt` 这种形式
- 不要试图"绕过去"，这是硬限制

### 2.4 文件 / 目录不存在

**错误长这样**：
```
文件不存在：notes.txt
```

**怎么做**：
- 想**新建**：改用 `write_file`，一次写完整内容（会自动建目录）
- 想**改已有**：先 `list_dir` 确认真实名字，别凭印象
- **不要**用 `make_dir` 去建一个同名的"文件"，那是目录不是文件

### 2.5 内容不匹配

**错误长这样**：
```
文件里没有找到：订单数：27
```

**为什么**：`replace_in_file` 的 `find` 必须是文件里**真实存在**的原文。

**怎么做**：
1. 先 `read_file` 看清实际内容
2. 原样复制那段文字（包括标点和空格）
3. 再替换

### 2.6 危险命令被拒

**错误长这样**：
```
被安全策略拒绝
```

**为什么**：`format` `diskpart` `shutdown` 这类命令永久禁止。

**怎么做**：不要重试，不要换个写法绕过。直接收尾说明原因。

### 2.7 命令要人按键

**错误长这样**：
```
会停下来等键盘输入
```

**怎么做**：去掉 `pause` `choice` `set /p` `Read-Host`，再跑。

### 2.8 脚本或命令报错（退出码非 0）

**错误长这样**：
```
运行 run_ps1 x.ps1 结束，退出码 1
--- 错误输出 ---
...具体报错...
```

**怎么做**：
1. **看错误输出那几行**，它通常直接说了哪一行错了、缺什么
2. 常见原因：
   - 变量没定义 → 检查变量名拼写
   - 缺少引号 → 路径有空格要加引号
   - 命令不存在 → 确认系统有没有这个命令
   - 类型不对 → 字符串转数字要 `[int]` 或 `[double]`
3. 用 `replace_in_file` 或 `set_line` 只改出错那行，**不要整份重写**
4. 再跑一次

### 2.9 超时

**怎么做**：
- 命令可能卡住了（比如在等输入、或者在下载大文件）
- 换一条更快返回的命令
- 把大任务拆小

### 2.10 输出不是合法 JSON

**怎么做**：重新输出，严格只输出一个 JSON 对象，不要加解释、不要代码块。

### 2.11 步数用完了 / 时间到了

**为什么**：任务太复杂，或者一直在绕。

**怎么做**：
- 说明已经做到哪一步、还差什么
- 如实收尾，不要谎报完成

## 3. 反复出错的自我诊断

连续失败 2 次之后，**停下来问自己三个问题**：

```
问题 1：我在解决真正的问题吗？
        错误说的是网络，我却去改文件名 → 没在解决真问题

问题 2：我改了什么？
        参数完全没变就重试 → 结果当然一样

问题 3：这条路走得通吗？
        同一个工具失败三次 → 换工具，或承认做不到
```

**判断"该换了"的标准**：

| 情况 | 判断 |
|---|---|
| 改了参数再试 → 还是同样错 | 这条路有问题，换路 |
| 换了工具 → 还是同样错 | 是环境问题，不是工具问题 |
| 错误和操作无关 | 别硬分析，按错误本身的类型处理 |
| 已经失败 3 次 | 停下来，如实说明，不要再试 |

---

## 4. 什么时候该放弃

以下情况**直接收尾**，不要继续试：

- 安全策略拒绝（永远不通过）
- 连续 3 次同样失败
- 网络不通且本地也解决不了
- 任务本身不可能完成（比如要求写 workspace 外）

收尾时要说清三件事：
```
1. 卡在哪一步
2. 错的具体原因
3. 已经做成了什么（如果有）
```

格式：`出错了：<原因>。（已经做了：<部分成果>）`
