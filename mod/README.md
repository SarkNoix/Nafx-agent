# Nafx 插件（mod）系统

一个 mod 就是一个 `.mod.json` 文件，放在这个目录下。
**不用改任何源码，不用重启模型**——agent 下次跑任务时自动加载。

卸载？删掉文件就行。

---

## 三种打开编辑器的方式

| 方式 | 怎么用 | 什么时候用 |
|---|---|---|
| **双击 `run-mod-editor.bat`** | 起 8070 服务 + 自动开浏览器 | 平时用这个 |
| 双击 `mod-editor-standalone.html` | 直接打开，不需要服务 | 8070 起不来时 |
| `http://127.0.0.1:8090/editor` | 借用面板的进程 | 面板在跑时 |

**三种方式功能完全一样。** 独立版的数据是生成时内联进去的，
改了 `config.json` 之后要重新生成（`run-mod-editor.bat` 会自动做，或者手动跑 `gen-standalone.ps1`）。

## 编辑器能改什么

### ① 基本信息

```json
"id": "coder-mode",       // 文件名主体，只能用英文数字和 . _ -
"name": "程序员模式",      // 面板上显示的名字
"version": "1.0",
"enabled": true           // false = 暂时不生效
```

### ② 配置

勾上才写进 mod。**只勾你真正想改的。**

| 字段 | 生效时机 | 说明 |
|---|---|---|
| `temperature` | 立即 | 越低越稳，干活用 0.1-0.4 |
| `maxSteps` | 立即 | 最多几步，复杂任务调高 |
| `maxTokens` | 立即 | 每次最多生成多少 token |
| `personalPrompt` | 立即 | 你的个人习惯 |
| `context` | **要重启模型** | 上下文窗口 |
| `threads` | **要重启模型** | CPU 线程数 |

### ③ 工具

- **取消勾选** = 在这个 mod 里禁用该工具
- **右边输入框填字** = 换掉工具说明

**改描述对行为影响很大。** 模型非常依赖工具说明的措辞。
比如把 `run_cmd` 的描述改成「跑命令前必须先说明要跑什么」，它真的会先说。

工具按 8 个组分类（文件/执行/系统/网络/数据/查询/流程/技能），可以搜索、折叠、只看已改的。

### ④ 人设 / 规则

追加到系统提示词末尾。写「你是谁、怎么说话、什么必须做、什么不许做」。

编辑器里带 4 个现成模板：程序员助手 / 严谨模式 / 极简模式 / 讲清楚型。

### ⑤ 补充文档

每份文档跟着人设一起发给模型。适合放命名规范、术语表、项目背景。

可以加、删、上下移动。

### ⑥ 加载时执行的脚本

PowerShell，agent 每次启动跑一次。

```powershell
$env:MY_MODE = 'coder'
Write-Output 'coder-mode 已加载'
```

编辑器里有「检查语法」按钮，写完可以先用它过一遍。

> ⚠️ 这是**真的执行代码**，权限和 agent 一样。别加载来路不明的 mod。

## 做完之后

1. 点 **「下载 mod 文件」**（或按 `Ctrl+S`）
2. 浏览器存一个 `你填的id.mod.json`
3. **放进这个目录**（`E:\Nafx\mod\`）
4. 跑个任务，看 `agent/logs/run_*.txt` 里有没有：

```
[mod] 配置 coder-mode.temperature
已加载 1 个 mod：程序员模式
[mod] coder-mode 改描述 run_cmd
[mod] 追加人设/文档 312 字符
[mod] coder-mode 脚本执行完成
```

## 自带的两个例子

| 文件 | 干什么 | 默认 |
|---|---|---|
| `coder-mode.mod.json` | 程序员模式：温度 0.1、40 步、改前必须先读 | **停用** |
| `brief-mode.mod.json` | 极简模式：回答一句话，200 token 封顶 | **停用** |

想用就把 `"enabled": false` 改成 `true`，或者在编辑器里勾上「启用」重新下载。

## 多个 mod 会叠加

按**文件名排序**加载，后面的覆盖前面的。

```
a.mod.json   config.temperature = 0.5
b.mod.json   config.temperature = 0.1   ← 最终 0.1
```

**人设和文档是全叠加的**（不覆盖，都拼进去）。

**⚠️ 注意上下文**：每个 mod 的 prompt 和 docs 都会进提示词。
编辑器右上角有「预估 +N token」，**超过 600 就该留意**，超过 1200 会挤占正常任务的上下文。

## 常见问题

**改了没反应？**

1. 文件名是 `.mod.json` 结尾（不是 `.json`）
2. `enabled` 是 `true`
3. 文件直接放在 `mod/` 下（不是子目录）
4. 看 agent 日志里有没有 `[mod]` 开头的行

**8070 打不开？**

`run-mod-editor.bat` 双击后有个黑窗口，看里面有没有报错。
实在不行直接用 `mod-editor-standalone.html`——双击就能用，功能一样。

**改了 context 没生效？**

`context` / `threads` 是模型启动参数，要重启模型（重新双击 `Nafx.bat`）。

**独立版的数据过时了？**

跑一下 `gen-standalone.ps1`，或者双击 `run-mod-editor.bat`（会自动更新）。

**JSON 报错？**

用编辑器做，它生成的 JSON 一定合法。手写容易漏逗号——编辑器有实时校验。
